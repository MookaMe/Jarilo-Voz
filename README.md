# Jarilo — Teaser V3 revisado

Materiais de pré-lançamento em versões clara e escura, com mensagens de expectativa.

## Baixar os arquivos

- **[Baixar o ZIP completo](Jarilo-V3-Revisado.zip?raw=true)** — HTML editável, fontes, imagens, PDFs, vídeos e instruções.
- [Abrir o PDF de apresentação](Jarilo-V3-Teaser.pdf).

Depois de baixar o ZIP, extraia a pasta inteira e abra **index.html**.
O pacote inclui as artes de feed, os stories com bases para enquete nativa e os Reels de 8 segundos nos dois temas.
Os vídeos estão sem trilha sonora. Nenhuma peça foi publicada em redes sociais.

A mensagem preserva a surpresa: **“Prepare-se. Um novo Jarilo vai te encontrar.”**
